# Code of conduct

Be respectful, constructive, and precise. Welcome participants regardless of
background, identity, experience, or disability. Critique technical work rather
than people. Harassment, threats, discriminatory abuse, impersonation, and sharing
someone's private information without consent are unacceptable.

This policy applies to repository issues, reviews, discussions, and other project
spaces. Maintainers may edit or remove abusive content and restrict participation
proportionately. Report concerns through a private maintainer contact where one
is available. If none is available, request a private contact without disclosing
sensitive details publicly. Maintainers should explain moderation decisions when
safe and consider good-faith appeals. Do not retaliate against reporters.
