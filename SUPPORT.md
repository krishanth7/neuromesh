# Support

For setup help or reproducible bugs, open an issue with your OS, Rust version,
commit, exact command, expected behavior, and sanitized output. Search existing
issues first. Feature requests should include a use case and testable acceptance
criteria. There is no commercial support or availability guarantee.

For security concerns, follow [SECURITY.md](SECURITY.md). Never post private keys,
credentials, private reports, or sensitive network configuration.
