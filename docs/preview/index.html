Authenticated session lifecycle

1 · QUIC transport up 2 · mutual TLS 1.3 3 · exporter-bound proof 4 · allowlist + expected NodeId 5 · NMP/1 request/response 6 · explicit close report

Sequence executed by the localhost experiment above and asserted by the integration suite: every step must succeed before a peer may be registered — discovery hints never grant trust.

Peer health state machine

Healthy · observation fresh Suspect · silent ≥ 2 s Unavailable · silent ≥ 5 s observe() → Healthy remove() · explicit only

The registry is a pure state machine: callers supply monotonic time and thresholds (2 s suspect / 5 s failure in the test contract). No timers run inside the library, and an unavailable peer keeps its slot until it is explicitly removed — conceptual animation; the measured timeline above is the only real data on this page.
